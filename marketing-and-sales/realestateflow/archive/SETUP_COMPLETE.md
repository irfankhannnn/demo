## 💡 Pro Tips

✅ **Always use the spacing scale** - No random pixel values  
✅ **Reference color tokens** - Ensures consistency  
✅ **Use component patterns** - Copy from components.md  
✅ **Apply Hinglish correctly** - 70% English + 30% Hindi  
✅ **Test on mobile** - All components are responsive  
✅ **Check contrast** - Text should pass WCAG AA  
✅ **Use CSS variables** - For easy customization
