## 🎯 Common Tasks

### Generate Instagram Post
1. Open NANO-BANANA-USAGE-GUIDE.md (section "Example 1: Instagram Post")
2. Copy the prompt template
3. Replace [MESSAGE] with message from NANO-BANANA-BRIEF.json
4. Run with /nano-banana
5. Validate with checklist

### Create Email Template
1. Use colors: Navy (#0F3A66), Blue (#1E40AF), Green (#22C55E)
2. Use fonts: Poppins + Inter
3. Dimensions: 1200×300px for header
4. Reference: NANO-BANANA-BRIEF.json → creativeDimensions
5. Validate against conformanceChecklist

### Build Website
1. Copy brand-styles-authority.css to project
2. Link Google Fonts URL
3. Use CSS variable classes (.btn-primary, .card, etc.)
4. Test responsive breakpoints
5. Ensure 60% whitespace on layouts

### Brief External Designer
1. Send 4 files:
   - NANO-BANANA-BRIEF.json
   - NANO-BANANA-USAGE-GUIDE.md
   - BRAND-IDENTITY-AUTHORITY-ON-BUDGET.md
   - design-tokens-authority.json
2. Include conformanceChecklist in approval process
3. Validate all deliverables before payment

## 🔄 Workflow: 5 Minutes to First Creative

```
1. COLLECT (1 min)
   Open NANO-BANANA-BRIEF.json
   
2. EXTRACT (1 min)
   Copy colors: #0F3A66, #1E40AF, #22C55E
   Note fonts: Poppins + Inter
   
3. BUILD (2 min)
   Write prompt using NANO-BANANA-USAGE-GUIDE.md template
   
4. EXECUTE (1 min)
   Run: /nano-banana create-image --brief NANO-BANANA-BRIEF.json --prompt "[your prompt]"
   
5. VALIDATE
   Check conformanceChecklist
   Publish!
```

## 💡 Pro Tips

✅ **Always use hex codes** → #0F3A66 (not "navy")  
✅ **Always mention whitespace** → "60% minimum"  
✅ **Always include both fonts** → "Poppins + Inter"  
✅ **Always reference the brief** → "NANO-BANANA-BRIEF.json"  
✅ **Always validate** → Use conformanceChecklist before publishing  

❌ **Never use other colors** → Only Navy, Blue, Green, and neutrals  
❌ **Never skip whitespace** → Always 60% minimum  
❌ **Never use only one font** → Poppins AND Inter  
❌ **Never skip validation** → Checklist is mandatory
