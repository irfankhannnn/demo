## 🚀 QUICK START (Choose Your Method)

### **METHOD 1: Browser Screenshot (EASIEST) ⭐**

**Time:** 5-10 minutes | **Quality:** ⭐⭐⭐⭐ | **Tools:** Just your browser

**Step 1:** Open the HTML file
```bash
Open: realtyflow-instagram-production.html
In: Chrome, Firefox, or Safari
```

**Step 2:** Open Developer Tools
```bash
Press: F12 (or Ctrl+Shift+I on Linux/Windows, Cmd+Option+I on Mac)
```

**Step 3:** Toggle Device Mode
```bash
Press: Ctrl+Shift+M (or Cmd+Shift+M on Mac)
```

**Step 4:** Set Viewport Size
```bash
At top of browser:
1. Click dropdown (shows device name)
2. Type: "1080x1080" in dimensions
3. Press Enter
```

**Step 5:** Screenshot Each Post
```bash
For each post:
1. Right-click on the post area
2. Select: "Capture screenshot"
3. Browser saves as PNG automatically
4. Chrome saves to: Downloads folder

Rename files:
- Screenshot → 1_light_pain.png
- Screenshot → 2_light_solution.png
- Screenshot → 3_light_feature.png
- Screenshot → 4_light_proof.png
- Screenshot → 5_light_comparison.png
```

**Step 6:** Upload to Instagram
```bash
1. Go to Instagram.com
2. Click "Create" (+)
3. Upload each PNG
4. Add captions (see below)
5. Post or schedule
```

✅ **Done!** Your Instagram posts are live!

## 🚨 TROUBLESHOOTING

**Problem: Posts look pixelated**
→ Solution: Ensure export is 1080x1080px at 72 DPI minimum

**Problem: Text not readable in thumbnail**
→ Solution: Use larger font sizes (as designed)

**Problem: Instagram crops image incorrectly**
→ Solution: Ensure aspect ratio is perfect 1:1 (1080x1080)

**Problem: Colors look different on mobile**
→ Solution: Test on actual iPhone/Android before posting

**Problem: Low engagement**
→ Solution: Check posting time, hashtags, and caption quality
