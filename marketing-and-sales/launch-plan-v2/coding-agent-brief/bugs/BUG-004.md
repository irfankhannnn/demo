# LP HTML Pages Do Not Include Partials — Analytics + Cookie Banner Absent in Production Build

## Epic
ZEE-006 + ZEE-008 + ZEE-003 / PR-C + PR-D + PR-I + PR-E

## Story
ZEE-006-T3 — Inject LP cookie banner into all 12 LP pages
ZEE-003-T2 — LP analytics snippet in all LP `<head>` sections
ZEE-008-T2/T3 — LP rewrite using build pipeline

## Requirement
All 12 LP pages should use `{{> head.hbs}}`, `{{> cookie-banner}}`, and `{{> head-analytics}}` partial includes. Built `dist/` output should contain consent-gated PostHog, GA4, Pixel, LinkedIn, Hotjar.

## Current State
- Partials exist: `marketing-and-sales/creative/landing-pages/_partials/{head-analytics.hbs,cookie-banner.html,head.hbs}`.
- Source pages (e.g. `main/index.html`) are **standalone HTML** with inline Tailwind CDN — no `{{> ...}}` includes.
- Ran `npm run build:lps` in `build/` — `dist/main/index.html` still has Tailwind CDN, **zero** `posthog`, `cookieConsent`, or `gtag` references.
- `process-partials.js` only expands `{{> partial}}` tags; pages without tags pass through unchanged.

Evidence: `grep posthog dist/main/index.html` → no matches.

## Expected State
Each LP `index.html` uses partial includes; `dist/` pages contain analytics snippet and cookie banner; Tailwind CDN replaced by compiled `main.css`.

## Gap Analysis
PR-I delivered page content and JSON-LD but did not migrate pages to the partial-based template system PR-D designed. Build pipeline runs but is effectively a no-op for analytics integration.

## Impact
- **User:** No cookie consent on marketing site; DPDP non-compliance on LP surface.
- **Business:** Zero LP funnel analytics; cannot measure ad spend ROI.
- **Technical:** PostHog LP→CRM bridge broken at source (no anonymous LP session).

## Required Changes
1. Refactor all 12 LP `index.html` files to use `{{> head.hbs}}` / footer partials / `{{> cookie-banner}}`.
2. Replace Tailwind CDN `<script>` with `<link href="/assets/main.css">`.
3. Re-run `build:lps`; verify `dist/` contains analytics + cookie banner.
4. Add build-time test: `grep -l posthog dist/*/index.html | wc -l` equals 12.

## Acceptance Criteria
- All 12 built LP pages contain cookie banner HTML and head-analytics script.
- Lighthouse mobile run possible (ZEE-008-T7).
- `tests/analytics.spec.ts` LP scenarios pass against built `dist/`.

## Files Likely Impacted
- `marketing-and-sales/creative/landing-pages/*/index.html` (all 12)
- `marketing-and-sales/creative/landing-pages/_partials/head.hbs`
- `marketing-and-sales/creative/landing-pages/build/scripts/process-partials.js`
