## Cadence rules

- One post every 2-3 days
- 11am or 12pm IST publish (LinkedIn algorithm + Indian SaaS audience peak)
- 90 min comment-engage window after publish
- Cross-share to: Twitter, broker WhatsApp groups, Indian SaaS Slack #IndianFounders / #IndianStartups
- DM-route every "interested" → cal.com + LP

## Voice constants (use across all 5)

- Founder-personal, not corporate
- Mumbai-specific (locality names, broker culture, real-world examples)
- Specific numbers + names (with consent)
- 1 idea per post
- 200-280 words sweet spot
- 1 testimonial quote when applicable
- Hashtags: 2-3 max, real-estate + India + SaaS combinations

## Subsequent posts (Post 6-10)

- **Post 7** (Day 25, in `week-4-optimize-convert/day-25-case-study-seo-foundation.md`) — case study share
- **Post 8** (Day 30, in `week-4-optimize-convert/day-30-month-2-strategy.md`) — M1 retrospective + M2 strategy

## How AI agent should use these

When asked to "publish founder LinkedIn Post N":
1. Read corresponding markdown file
2. Pull "final draft"
3. Replace any tester-name placeholders (with consent confirmed)
4. Verify media is ready (photo / Loom / graphic)
5. Stop — founder publishes manually (LinkedIn account in founder's possession)

When asked to "rewrite Post N for new context" (e.g., Pune launch M2):
1. Read corresponding markdown
2. Apply skills `social-content` + `copywriting`
3. Adapt locality references + numbers + cohort details
4. Save as new file with `-pune` or `-m2` suffix
5. Don't overwrite originals
