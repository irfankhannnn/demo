# Sales OS — Qualification Playbook

Qualify fast so effort goes to real buyers. Lightweight for SMB brokers (no heavy BANT). Pairs with Attention OS DM handoff + WhatsApp lead-nurture.

## The 4 quick questions (in DM/WhatsApp)
1. **Team size?** (solo / 2–8 / 8–25+) → routes plan + path.
2. **Current lead tool?** (WhatsApp/Excel/other CRM/nothing) → pain depth.
3. **Lead volume/month?** → urgency + plan tier.
4. **Biggest pain?** (leakage / follow-up / team visibility / khata / calling) → demo focus.

## Routing
| Signal | Route |
|---|---|
| Solo + low volume | Self-serve **Free/Starter trial** (TRIAL CTA) |
| Team 2–25 + clear pain | **Demo** (DEMO CTA) → demo-script |
| Owner + multi-agent + WhatsApp chaos | Priority demo + ROI/leak math |
| Just curious / student | Nurture (broadcast/community), low effort |
| Developer / 25+ agents | Enterprise conversation |

## Buying triggers (lean in when present)
Lost a big deal recently · agent left with data · scaling team · commission dispute · competitor using a system · new project launch (lead flood).

## Decision makers
- **Owner (Rajesh Bhai)** = economic buyer, fast if ROI clear.
- **Sales Manager (Priya)** = champion, needs feature proof, recommends to owner.
- **Agent (Arjun)** = user/influencer, loves AI + mobile.
Map who you're talking to; arm the champion to sell internally (sales-enablement).

## Budget
Free → ₹999 → ₹2,999 → ₹5,999. Anchor on ROI (one extra deal pays for years). Disqualify gently if no pain + no budget + no authority.

## Output
Create lead with source + segment + pain + stage; hand to demo-script or trial onboarding. Log content attribution.
