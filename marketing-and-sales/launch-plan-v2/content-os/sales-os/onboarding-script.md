# Sales OS — Onboarding Script (First 7 Days)

Activation in week 1 predicts retention. Drive to the aha moment (AI calling + organized pipeline) fast. Pairs with WhatsApp customer-success + Automation OS activation-scoring.

## Day-by-day
| Day | Action | Aha |
|---|---|---|
| 0 | Welcome + import 10 leads together | "sab ek jagah" |
| 1 | Set first follow-up reminders | "ab nahi bhulega" |
| 2 | Turn on **AI calling** on a real lead | the wow moment |
| 3 | Invite team + set RBAC (agencies) | control |
| 4 | Add properties / inventory + match a buyer | "turant share" |
| 5 | Set up khata/settlement | "hisaab clear" |
| 7 | Week-1 review: show their dashboard numbers | proof of value |

## Activation milestones (target 3/4 in week 1)
Leads added · follow-up set · first AI call · team member invited (or buyer matched, for solo).

## Delivery
Personal WhatsApp guidance + short in-app/loom tutorials. Proactive, not reactive — reach out before they get stuck.

## If stalling
No login 48h → personal nudge + offer a 10-min setup call. Low feature use → targeted mini-tutorial. Escalate at-risk to founder.

## Exit to success
After week-1 win → move to ongoing customer-success cadence; ask for review + referral.
