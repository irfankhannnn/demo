# Sales OS — Follow-up Script

Most deals close on follow-up — ironic for a follow-up product, so model the behaviour. Pairs with WhatsApp lead-nurture + demo-followup.

## Cadence (post-demo / warm lead)
| Touch | Day | Message intent |
|---|---|---|
| 1 | 0 (≤1h) | Recap + trial link + address the one objection |
| 2 | +1 | "Setup mein help chahiye? main guide kar dun" (remove friction) |
| 3 | +3 | Case study / ROI math for their segment (FW-CASE) |
| 4 | +5 | AI-calling clip + "ek lead pe try karo" |
| 5 | +7 | Decision nudge + limited offer / extended trial |
| 6 | +12 | "Koi pressure nahi" re-engage + best content |
| 7 | +21 | Break-up: "abhi nahi toh kab? main yahan hoon" |

## Principles
- One CTA per message; value before ask.
- Reference their specific pain + the content they engaged.
- Always propose a concrete next step (slot/trial), never "let me know".
- Stop on request; move stale → nurture-bot/broadcast.

## Channel
WhatsApp primary (templates in distribution-os/whatsapp/message-templates.md); call for high-value owners.

## Output
Update lead stage each touch; log to pipeline (pipeline-manager). On stall after 7 touches → long-term nurture.
