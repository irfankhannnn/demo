# GTM OS — 30/60/90 Day Roadmap (Phase 14)

Highest-leverage actions first. Sequenced so content + distribution start immediately (cheap, compounding) while engineering instrumentation catches up.

## Days 0–30 — Launch & Measure
**Theme:** Get content live, start conversations, see the funnel.
- **Content OS:** run the 14-day launch plan, then weekly cadence (5–6 reels/wk). Establish 9 characters + 5 franchises.
- **Attention/Distribution:** IG daily + stories; founder-engine daily (comments/connects/DMs); WhatsApp lead-nurture live; LinkedIn founder authority started.
- **Sales OS:** objections + qualification + demo-script in use; book first demos.
- **Engineering (highest leverage):** **EP-1 attribution + EP-2 events + minimal dashboard** (Sprint 1). UTM capture on signup. Until shipped, track funnel in a sheet.
- **KPI targets:** 1k IG followers, hook rate >40%, 10+ DM convos, 3–5 demos, attribution live.

## Days 31–60 — Convert & Automate
**Theme:** Turn reach into demos; remove manual friction.
- **Content/Distribution:** double down on winning franchises; add CT-AI + CT-CASE weekly; FB-group seeding; light paid on proven reels; launch IG broadcast channel.
- **Sales OS:** follow-up + closing + onboarding scripts; demo-followup automation.
- **Engineering:** **EP-3 inbound capture** (IG/FB webhooks, keyword auto-reply, Meta Lead Ads, AI auto-qualify) + start **EP-4 sequences** + WhatsApp Business API (Sprints 2–3).
- **KPI targets:** 5k followers, speed-to-lead <5 min, 15–20 demos, 5+ trials, no-show <30%.

## Days 61–90 — Optimize & Scale
**Theme:** Make it a predictable, measured engine.
- **Content/Distribution:** lock theme-day calendar; batch by character; weekly testimonial; scale winning paid; WhatsApp community + monthly founder live.
- **Sales OS:** referral motion live post-activation; win-back for inactive trials.
- **Engineering:** **EP-5 scoring + EP-6 referral + EP-7 full dashboard** (CAC/LTV/cohorts/content-ROI) (Sprints 4–5) + observability.
- **KPI targets:** 10k+ followers, predictable demos/week, defined CAC + LTV:CAC ≥3:1, content-`OPP-*` ROI visible, referral % tracked.

## Prioritization principle
Cheapest compounding first (content + founder engine), then conversion automation, then optimization. Never build scoring/dashboards before attribution exists. Re-prioritize monthly off `growth-dashboard.md`.

## Owner map
Content/creative → Content Factory + Creative agents. Distribution/founder → founder + community. Sales → SDR/nurture-bot. Engineering → Builders (architect/PR) per `implementation/backlog.md`. Measurement → growth-strategist/oracle.
