# WhatsApp — Referral Strategy

Brokers trust brokers — word-of-mouth is the **cheapest CAC** and the #1 trust signal in this market (`02-market-research §2.2, §9.2`). Turn happy customers + community members into a referral engine. Pairs with `customer-success.md` (who's ready), `community.md` (warm pool), and Automation OS referral-tracking (`automation-os/workflow-map.md` seq 9).

> **Timing rule:** never ask before value is delivered. Ask **after an activation win** — deal closed via the app, week-1 milestones hit, or unprompted positive feedback. A well-timed ask to a delighted customer converts; a premature one burns goodwill.

---

## 1. When to ask (trigger map)

| Trigger | Source | Readiness |
|---|---|---|
| Deal closed via app | customer-success | 🟢 best moment |
| Week-1 milestones (≥3/4) hit | activation event | 🟢 strong |
| Unprompted praise / 👍 | any WhatsApp reply | 🟢 strike now |
| Demo'd but not yet bought | demo-followup | 🟡 "refer a peer" angle |
| Engaged community member | community | 🟡 warm |
| Event / founder-network contact | founder-engine | 🟡 personal ask |

## 2. The reward mechanics

| Party | Reward | Issued on |
|---|---|---|
| **Referrer** (existing customer) | 1 free month / feature credit / extended plan | referee converts to paid |
| **Referee** (new) | free setup + extended trial | signs up via referrer's link/code |
| **Top referrers** (3+ conversions) | "RealEstateFlow Partner" badge + early features | milestone |

Double-sided rewards out-perform one-sided. Reward the *referrer on conversion* (not on send) to keep quality high. Track code + source so `pipeline-manager` attributes referral→paid.

## 4. Make sharing effortless
- **1-tap WhatsApp share** with pre-written message + ref-link (above).
- **Ref-code** they can drop in their own broker groups.
- **Shareable win-card** (their result as an image) → "share-able pride" → organic referrals.
- Public thanks (with consent) → social proof → more asks land.

## 5. Sources (warm pools, ranked)
1. Paying + activated customers (highest convert).
2. Community members (`community.md` Wins group).
3. Demo'd-but-not-yet (refer a peer angle).
4. Event / meetup + founder network.
5. Broadcast list repliers (`founder-broadcast.md`).

## 6. Amplify loop
Referred wins → CT-CASE / CT-PROOF content (with consent) → more inbound + more referrals. Spotlight top referrers in community (status reward). Tie referral asks into the monthly success review so it's a *ritual*, not a one-off.

## 7. Rules & compliance
Ask once per win; don't nag. Reward only on genuine conversion. Referee must opt in (no cold-adding their contacts). Keep the ask personal and human — never a mass blast. Honour any "abhi nahi".

## 8. Metrics (→ `growth-dashboard.md`)
Referrals sent, referral→demo, referral→paid, **referral as % of new customers** (target 20%+, `sales-os/customer-journey.md`), top-referrer leaderboard, reward redemption. Low referral % = the ask isn't happening → enforce the post-win trigger in `customer-success.md`.
