# WhatsApp — Community Strategy

A WhatsApp Community / group for engaged brokers ("RealEstateFlow Brokers Club") — retention + word-of-mouth + referral engine.

## Purpose
Off-feed retention, peer trust, feedback, referrals, beta testing. Turns followers into a tribe.

## Structure
- Announcement-only main channel (founder tips, updates).
- Optional moderated discussion group (broker Q&A, peer help) — keep value high, spam zero.

## Rituals (predictability = retention)
- **Mon:** "Pipeline Cleanup" tip.
- **Wed:** member spotlight / win.
- **Fri:** "AI win of the week" + feature drop.
- Monthly: founder live Q&A / voice note AMA.

## Rules
Value first, no broker-vs-broker poaching, no spam. Light moderation. Members get early features + lead magnets.

## Growth
Invite from IG broadcast, demos, trials, events. "Join the club" CTA in bio/stories.

## Conversion
Community → trials/demos via genuine value + exclusive offers; community members are prime referral sources (see referral.md).

## Metrics
Members, active %, messages/week, community→demo, community→referral. Feed growth-dashboard.
