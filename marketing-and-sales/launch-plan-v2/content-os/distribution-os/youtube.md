# Distribution OS — YouTube

**YouTube = long-tail SEO + depth + repurposing reservoir.** Shorts mirror IG reels for reach; long-form builds searchable authority and supports BOFU research ("real estate CRM India review", "best CRM for property dealers").

## Audience
- Brokers researching tools (high intent, longer sessions).
- Owners evaluating CRMs before a demo.
- New joiners learning the trade (top-of-funnel discovery).

## Posting frequency
- **Shorts:** 4–5/week (repurpose IG reels 1:1).
- **Long-form:** 1/week (or 1/2 weeks). Consistency beats volume.

## Content mix (by CT-*)
| Format | CT-* | Examples |
|---|---|---|
| Shorts | CT-DRAMA / CT-EDU / CT-AI | repurposed reels |
| Tutorials / walkthroughs | CT-DEMO | "RealEstateFlow setup in 10 min", "AI calling demo", "Khata settlement explained" |
| Education | CT-EDU / CT-CRM | "How Mumbai brokers stop lead leakage", "WhatsApp → CRM migration" |
| Case studies | CT-CASE | "How [agency] doubled site visits" |
| Founder / vision | CT-FOUNDER / CT-AUTHORITY | building-in-public, RE market takes |

## CTA strategy
Description link + pinned comment + end-screen → demo/trial. Cards to related videos for session time. CTA: DEMO, TRIAL, FOLLOW(subscribe).

## Lead capture
SEO titles/descriptions with demo link; lead magnets in description (CTA-LEAD-MAGNET); end-screen demo CTA; pinned comment with link. Tag `leadSource = youtube`.

## SEO targets (title + description + tags)
"real estate CRM India", "CRM for real estate brokers", "AI calling for real estate", "MagicBricks / 99acres lead management", "best CRM for property dealers Mumbai", "Pune real estate CRM", "broker follow-up software". Use Hinglish + English title variants.

## Repurposing engine (1 long-form → a week of content)
- 1 long-form tutorial → 3–4 Shorts + 1 IG carousel + 1 LinkedIn document + 1 blog post + 3 WhatsApp broadcast tips.
- IG reels → Shorts (batch weekly).
- Case-study reel → full long-form interview with the customer.

## Publishing workflow
Render in `my-video/` (Remotion) / edit → upload → optimise title/desc/tags/thumbnail → pin demo CTA → add end-screen + cards → cross-link. Schedule natively in YouTube Studio.

## Metrics
Shorts views, long-form watch time / retention, search impressions + CTR for target keywords, description-link clicks, YouTube→demo. Feed `growth-dashboard.md`.
