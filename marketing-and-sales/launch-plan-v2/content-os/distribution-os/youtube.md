# Distribution OS — YouTube

**YouTube = long-tail SEO + depth + repurposing reservoir.** Shorts mirror IG reels; long-form builds searchable authority and supports BOFU research ("real estate CRM India review").

## Audience
Brokers researching tools, owners evaluating CRMs, new joiners learning the trade. Higher intent, longer sessions.

## Posting frequency
Shorts: 4–5/week (repurpose IG reels). Long-form: 1/week (or 1/2 weeks). Consistency > volume.

## Content mix (by CT-*)
| Format | CT-* | Examples |
|---|---|---|
| Shorts | CT-DRAMA/CT-EDU/CT-AI | repurposed reels |
| Tutorials / walkthroughs | CT-DEMO | "RealEstateFlow setup in 10 min", "AI calling demo" |
| Education | CT-EDU/CT-CRM | "How Mumbai brokers stop lead leakage" |
| Case studies | CT-CASE | "How [agency] doubled site visits" |
| Founder/vision | CT-FOUNDER/CT-AUTHORITY | building-in-public |

## CTA strategy
Description + pinned comment + end-screen → demo/trial. Cards to related videos for retention. CTA: DEMO, TRIAL, SUBSCRIBE(FOLLOW).

## Lead capture
SEO-optimised titles/descriptions with demo link; lead magnets in description (CTA-LEAD-MAGNET); end-screen demo CTA. Tag source = `youtube`.

## SEO targets
"real estate CRM India", "CRM for brokers", "AI calling for real estate", "MagicBricks lead management", "best CRM for property dealers Mumbai/Pune". Hinglish + English titles.

## Repurposing
- IG reels → Shorts (1:1).
- Long-form tutorial → 3–4 Shorts + 1 IG carousel + 1 LinkedIn post + blog.
- Case-study reel → full long-form interview.

## Publishing workflow
Render in `my-video/` (Remotion) / edit → upload → optimise SEO → pin demo CTA → cross-link. Schedule via native/Blotato where supported.
