# Distribution OS — Facebook

**Facebook = broker groups (trust seeding + lead listening) + page (reach overflow) + Lead Ads (paid pipeline).** Indian brokers and owners live in FB groups for project leads and CP networking — it's where trust is built before they ever DM.

## Audience
- Owners 35–55 (Rajesh Bhai) — active in broker/CP groups, deal-hunting, peer-trust driven.
- Brokers in CP groups (lead exchange, project leads).
- Lead-ad audiences (interest + lookalike from existing customers).
Mood: community, deal-hunting, "show me you're legit."

## Posting frequency
- **Page:** 4–5/week (cross-post IG reels + 1–2 native).
- **Groups:** daily genuine participation (answer a question, never spam).
- **Ads:** always-on lead-gen once a creative is proven organically.

## Content mix (by CT-*)
| Surface | CT-* | Note |
|---|---|---|
| Page feed | CT-DRAMA / CT-EDU / CT-CASE | cross-post winning IG reels |
| Groups | CT-EDU / CT-AUTHORITY | give value, soft-mention, let bio sell |
| Lead ads | CT-DEMO / CT-CASE / CT-AI | promote proven organic creatives |

## CTA strategy
- Page: comment keyword / DM / demo (CTA-DEMO, CTA-DM).
- Groups: helpful answer → profile/DM (never hard pitch). Occasionally drop a free tool (CTA-LEAD-MAGNET).
- Ads: instant-form lead capture → WhatsApp follow-up <5 min (CTA-WHATSAPP).

## Lead capture
FB **Lead Ads** (instant forms — name, phone, "current lead tool?") + Messenger + group DMs. CAPI/Conversions API for optimization (see media-buyer + `automation-os/integrations.md`). Tag `leadSource = facebook_ads | facebook_group`.

## Group strategy (the real engine)
1. Join the top 10–15 Mumbai + Pune broker/CP groups.
2. Daily: answer ONE lead-management/follow-up/commission question with genuinely useful advice.
3. Build name recognition; let your profile + bio do the converting.
4. Weekly: share a free resource (follow-up tracker, leakage calculator) — value, not ad.
5. Track which groups send DMs → double down.

## Repurposing
IG reels → FB reels/feed (1:1) · IG carousels → FB image posts · case studies → group "success stories" (with permission) · LinkedIn hot-takes → FB page text posts.

## Publishing workflow
Content factory → Blotato (IG+FB simultaneously) → group participation manual (authenticity) → winning posts promoted as Lead Ads via meta-ads MCP → leads flow to `/api/marketing/events` → WhatsApp nurture.

## Metrics
Group DMs started, lead-ad CPL, lead-ad → demo rate, page reach (overflow), cost per qualified lead by group/ad. Feed `growth-dashboard.md`.
