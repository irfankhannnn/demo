# Instagram — Carousels (The Save Engine)

Carousels win saves + dwell time → algorithm boost + reference value. Best for `CT-EDU`, `CT-CASE`, `CT-AUTHORITY`.

## Structure
| Slide | Job |
|---|---|
| 1 (cover) | Hook (`HK-*`) — `VP-THUMB-EDU`, big promise/number |
| 2 | Reframe the pain / "why this matters" |
| 3–7 | One point per slide (mistake, step, stat) |
| 8 | Recap / takeaway |
| 9 | CTA (`CTA-SAVE`/`CTA-DEMO`) + "save & share" |

## Design rules
Inter font, `#2563EB` accent, one idea per slide, big text (mobile), consistent template, logo bug, ₹/lakh/crore numbers. 6–9 slides.

## When carousel vs reel
- **Carousel:** lists, frameworks, step-by-steps, data, case breakdowns (reference/save).
- **Reel:** emotion, drama, demo, reach.

## Best frameworks
FW-MISTAKE ("5 galtiyan"), FW-CRM ("CRM kya hota hai"), FW-LEAD-LEAKAGE (the math), FW-CASE (before→after), FW-MYTH.

## Cadence
2/week. Caption = mini-blog (SEO Hinglish) + CTA. Cross-post to LinkedIn (document) + FB.

## CTA
SAVE primary; DEMO/LEAD-MAGNET secondary ("comment X for the template").
