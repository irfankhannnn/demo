# Instagram — DM Workflows

The DM is where attention becomes a qualified conversation. Integrates with `content-to-conversation.md`, Sales OS, and `distribution-os/whatsapp/`.

## Auto-reply keywords (set in IG/Meta tools)
| Keyword | Auto-DM |
|---|---|
| DEMO | "2-min AI-calling demo dekho 👉 {link}. Team size kitni hai?" |
| LEAK | "Yeh raha Lead-Leakage Calculator {link}. Abhi leads kahan track karte ho?" |
| SHEET | "Free Broker Follow-up Tracker 👇 {link}. Kitne leads/month aate hain?" |
| AI | "AI ko apne hi lead pe try karna hai? Number do, WhatsApp pe live dikhata hoon." |
| TRIAL | "Free trial (no card) 👉 app.realtyflow.in/signup. Help chahiye toh batao." |

## The DM script flow
```
1 Greet + deliver promised value (asset/link)
2 Qualify (max 2 Qs): team size? current lead tool?
3 Route: solo→TRIAL; team+pain→DEMO; curious→nurture
4 Handoff: "WhatsApp pe bhej dun? Wahan AI calling + inventory live dikhata hoon."
5 Capture number → create lead (source=instagram_dm) → Sales OS qualification
```

## Templates
- **Warm opener:** "Arre {{name}} 🙌 dekha aapne reel pe react kiya. Aapki agency mein abhi leads WhatsApp/Excel pe ya system pe?"
- **Objection in DM:** route to `sales-os/objections.md` snippets.
- **No-reply nudge (24h):** "Koi pressure nahi — bas yeh AI calling clip dekh lo, 60 sec 👉 {clip}."

## Rules
One ask per message. Never paste pricing first — sell the demo. Move richer convos to WhatsApp fast. Log every qualified DM for content attribution (which `OPP-*` drove it).
