# Instagram — Comments Strategy

Comments are an engagement signal AND a DM pipeline. Integrates with `content-to-conversation.md` and Sales OS.

## Comment-bait mechanics
- Ask a binary question in caption ("WhatsApp ya system? 👇").
- Keyword loop: "Comment 'LEAK' for the calculator."
- Hot take (FW-CONTRARIAN) → debate.
- "Tag a broker who…" → new viewers.

## Reply SOP
- Reply to EVERY comment in first 60 min (algorithm + trust).
- Buying-intent comment → "DM kar diya 🙌" → move to DM (never sell in public thread).
- Add a question back to keep threads alive.
- Heart genuine comments.

## Pinned comment
Pin a comment restating the CTA / the keyword / the demo link prompt.

## Moderation
Hide spam/competitor trolling; engage genuine objections publicly (mini FW-OBJECTION), then take details to DM.

## Comment → DM conversion
Intent signals: "price?", "kaise milega?", "demo?", "team ke liye?" → DM immediately with qualify flow. Log as `instagram_comment` lead source.

## Using comments as research
Recurring questions → new content opportunities (`OPP-*`) + objection updates (`sales-os/objections.md`).
