# Instagram — Follower-to-Demo Journey

The full path from cold viewer to booked demo, with drop-off points and fixes. Pairs with Sales OS `customer-journey.md`.

## The journey
```
Cold viewer → Follower → Engaged (save/comment) → DM → WhatsApp → Demo
```
| Stage | What moves them | Content/Lever | Drop-off & fix |
|---|---|---|---|
| Cold → viewer | scroll-stop hook | HK-* + CT-DRAMA at night | Weak hook → fix first 1s |
| Viewer → follower | series + profile value | retention-engine, pinned reels | No reason to follow → add franchise + clear bio |
| Follower → engaged | save/comment bait | CT-EDU, comment-bait | Passive → add CTAs + questions |
| Engaged → DM | keyword/lead-magnet | content-to-conversation | No ask → every pain reel gets a DM CTA |
| DM → WhatsApp | low-friction value | dm-workflows handoff | Friction → ask only for number + offer live demo |
| WhatsApp → demo | proof + AI wow + ROI | Sales OS qualification/demo-script | Stalls → send case study + AI clip, book slot |

## Conversion targets (tune in growth-dashboard)
Viewer→follower 2–4% · follower→DM ~1–2%/month · DM→WhatsApp 40% · WhatsApp→demo 30% · demo→trial/paid (Sales OS).
