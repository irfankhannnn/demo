# Instagram — Growth Loops

> **Phase 3 · Instagram Subsystem · RealEstateFlow (brand: RealtyFlow) · @realtyflow_india**
> The **compounding engines** behind follower + reach growth. A loop is content where the *output becomes the next input* — a save trains the algorithm to show more, a share recruits a viewer who becomes a follower. Integrates with `attention-os/virality-engine.md`, `attention-os/retention-engine.md`, `reels.md`, `carousels.md`, `comments.md`, and `follower-to-demo.md`.

**Audience reality:** brokers **forward to peer WhatsApp groups** (the #1 trust signal, research §2.2/§9.2) and **save business-useful content**. Loops are built on these two behaviours. Hinglish 70/30 + Marathi for Pune.

---

## 1. Save Loop
- **Mechanic:** reference content (frameworks, ₹-math, templates) → brokers save + re-open before client calls → saves train the algorithm → more cold reach → more saves.
- **Operationalize:** ship 2 CT-EDU carousels/week (`carousels.md`), every one ending `CTA-SAVE`. Tag "save this checklist." Lead-magnet keyword (LEAK/GUIDE) converts savers to DMs.
- **Fuel OPP-*:** OPP-013 (100→12 math), OPP-296 (₹5L galti), OPP-511 (property share).
- **Metric:** save rate; saved→DM via keyword.

## 2. Share / Tag Loop
- **Mechanic:** relatable drama/meme + "tag a broker" → tagged brokers become viewers → some follow → they tag the next.
- **Operationalize:** CT-DRAMA/MEME with `CTA-SHARE-007` ("share with that one agent jo abhi bhi Excel pe hai") / `CTA-COMMENT-015` (tag). Validate a shared frustration (research §10 moments).
- **Fuel OPP-*:** OPP-001 (200 unread POV), OPP-435 (2026 Excel), OPP-430 (mera lead kahan).
- **Metric:** shares/sends + tag count.

## 3. Series Loop
- **Mechanic:** recurring CH-* cast + franchises → followers return for "next episode" → consistent follows + watch-time.
- **Operationalize:** the 5 franchises on fixed weekdays (`reels.md §7`, `content-cadence.md §3`). Star the "Apna Properties" cast in stories BTS (`stories.md §5`) so the universe feels continuous.
- **Fuel OPP-*:** OPP-002/057/058 (drama), OPP-481/192 (AI series).
- **Metric:** follower growth + returning-viewer rate per series.

## 4. Collab Loop
- **Mechanic:** co-create with broker influencers / CP-group admins → shared audiences → cross-follows.
- **Operationalize:** see §8 collab playbook. Founder appears on RE pages/podcasts (`founder-engine.md`).
- **Metric:** follows from collab posts; new-audience reach.

## 5. SEO Caption Loop
- **Mechanic:** keyword-rich Hinglish captions → IG search + Google discovery over time → evergreen long-tail reach.
- **Operationalize:** see §7 caption formulas. Seed "real estate CRM", "lead leakage", "AI calling for brokers", "Mumbai/Pune broker" in captions + first comment.
- **Metric:** search-sourced reach (IG insights).

## 6. DM / Comment Relationship Loop
- **Mechanic:** 1:1 replies (`comments.md`, `dm-workflows.md`) → loyalty → these followers comment early on every new post → early engagement → boosted reach for everyone.
- **Operationalize:** the 60-min reply rule + warm DM nurture. Re-share good DM/story answers (anonymized) as proof.
- **Metric:** repeat-commenter rate; first-60-min comment velocity.

4. **Cadence:** 1 collab/week from Month 2 (`90-day-growth-strategy.md`).

## 10. The Flywheel

```
   ┌────────────────────────────────────────────────────┐
   │  Reach (drama/meme) → Follows (series) → Saves/Shares (edu)
   │        ↑                                        ↓
   │  Case studies ← Customers ← Demos ← DMs (comment/DM loops)
   └────────────────────────────────────────────────────┘
```
Each output feeds the next input: drama earns reach → series converts to follows → edu earns saves/shares (more reach) → loops open DMs → DMs become demos → demos become customers → customers become case studies → case studies earn more reach. Stories + broadcast are the **retention layer** spinning the wheel between posts.

## 12. Metrics per Loop

| Loop | Lead metric | Target signal |
|---|---|---|
| Save | save rate | edu beats reels on saves |
| Share/Tag | sends + tags | drama/meme lead |
| Series | returning-viewer % + follows | franchise retention |
| Collab | follows + DMs per collab | positive new-audience reach |
| SEO caption | search-sourced reach | grows month over month |
| DM/comment | first-60-min velocity | repeat commenters rise |

> Loops are judged by **compounding, not spikes**. A loop is working when this month's baseline reach/follows is higher than last month's *without* a viral outlier carrying it.
