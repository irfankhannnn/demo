# Implementation — User Stories

## EP-1 Attribution
- As an **owner**, I want each lead to show where it came from (IG reel, FB ad, referral) so I know what marketing works.
- As a **marketer**, I want UTM + `contentRef (OPP-*)` captured so I can tie demos back to specific content.
- As an **SDR**, I want to see the source + the content the lead engaged so my first message is relevant.

## EP-2 Event Ingest/Engine
- As the **system**, I want a single endpoint to receive marketing events (post published, comment, DM, lead-ad, download) so all channels normalize into one funnel.
- As a **marketer**, I want rules ("on Trial Inactive → win-back") configurable per tenant.

## EP-3 Inbound Capture
- As a **lead**, when I comment a keyword, I get an instant helpful DM.
- As an **SDR**, inbound DMs/comments/lead-ads auto-create an attributed lead so nothing is missed.
- As an **owner**, qualified inbound leads get an AI call within minutes (speed-to-lead).

## EP-4 Sequences
- As a **trial user**, I get a 7-day onboarding drip that gets me to my first AI call.
- As a **warm lead**, I get a consent-based nurture sequence I can stop anytime.
- As a **demo booker**, I get reminders so I don't no-show.

## EP-5 Scoring
- As an **SDR**, I want leads ranked by score so I work the hottest first.
- As a **CS/owner**, I want a health score + activation score so I can save at-risk customers.

## EP-6 Referral
- As a **happy customer**, I want a referral link + reward so I can invite peers easily.
- As an **owner**, I want to see referral-driven customers and reward payouts.

## EP-7 Dashboard
- As an **owner/founder**, I want a funnel view (reach→DM→demo→trial→paid→referral) with CAC/LTV and which `OPP-*` content drove demos, so I invest where it works.
