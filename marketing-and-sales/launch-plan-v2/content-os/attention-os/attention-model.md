# Attention OS — Attention Model

**How attention actually works for Mumbai/Pune real-estate brokers, and how the OS engineers it.** Integrates with frameworks (`FW-*`) and content types (`CT-*`).

## 1. The Scroll-Stop Equation
> **Stop probability = (Relevance × Emotion × Pattern-Interrupt) ÷ Time-to-hook**

- **Relevance:** broker recognises the situation in <1s (WhatsApp chaos, lost lead, commission).
- **Emotion:** fear > greed > status > humour > curiosity (see audience-research §4).
- **Pattern-interrupt:** a number, a bold claim, a face mid-reaction, a contrarian line.
- **Time-to-hook:** the visual + verbal hook must land inside **1 second**. Every extra second halves retention.

## 2. The 3-Second Rule (reel anatomy)
| Time | Job | Tool |
|---|---|---|
| 0.0–1.0s | Stop the scroll | `HK-*` hook + on-screen text + face/reaction |
| 1–3s | Confirm relevance ("this is me") | name the pain in their words |
| 3–15s | Deliver the one idea | `FW-*` structure |
| last 2–4s | Convert attention → action | `CTA-*` |

## 3. Pattern Interrupts that work for brokers
- ₹-number on screen ("₹50,000 gaya").
- Mid-action freeze (CH-OWNER pinching nose).
- "Stop doing X" / "Yeh galti band karo".
- Contrarian: "Market down nahi, tumhari leakage problem hai."
- POV framing: "POV: 200 unread WhatsApp messages".
- Marathi opener for Pune (instant in-group signal).

## 4. The Emotional Trigger Stack (what to pull, when)
1. **Fear of loss** → TOFU reach, FW-FEAR / FW-WHATSAPP-CHAOS / FW-LEAD-LEAKAGE.
2. **Greed/money** → MOFU desire, FW-REVENUE / FW-BAB.
3. **Status** → authority/aspiration, FW-AUTHORITY / FW-FOUNDER / FW-AGENCY-GROWTH.
4. **Humour/relatability** → reach + follows, CT-DRAMA / CT-MEME.
5. **Curiosity/novelty** → AI wow, FW-AI / FW-CURIOSITY.

## 5. The Attention → DM Ladder (AIDA, brokerised)
```
Attention  → scroll-stop hook (HK-*)              [reach]
Interest   → relatable pain named in ₹/Hinglish    [retention]
Desire     → proof + AI wow + transformation       [FW-CASE/FW-AI/FW-BAB]
Action     → low-friction ask (comment word/DM)     [CTA-*]
→ Conversation (DM/WhatsApp) → Demo                 [content-to-conversation.md]
```
Each rung maps to a framework + content type. A piece should own ONE rung as its job (don't try to do all four in one reel).

## 6. Attention Budgeting (portfolio rule)
Per 10 pieces: ~5 attention-grabbers (fear/drama, TOFU), ~3 desire/proof (MOFU), ~2 conversion (BOFU). This keeps reach high while still producing demos. Mirrors the content-plan score weighting (lead-gen weighted highest but reach feeds it).

## 7. Measuring attention
- **Hook rate** = 3s views ÷ reach (target >45%).
- **Hold rate** = avg watch time ÷ length (target >55%).
- **Action rate** = (saves+shares+comments+DMs) ÷ reach.
Track in `growth-dashboard.md`. A low hook rate = fix the first second, not the topic.
