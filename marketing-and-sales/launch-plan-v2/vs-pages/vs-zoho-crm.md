### Section 3 — Feature comparison

**H2:** Real-estate-specific features

#### Buyers / Owners / Properties / Khata
- **Zoho**: stock CRM uses Contacts + Deals + Products. To make it work for real estate, you configure custom modules. 2-7 days of admin work + ongoing maintenance.
- **RealEstateFlow**: Buyers, Owners, Properties, Tenants, Khata book are first-class entities. Zero configuration.
- **Verdict**: RealEstateFlow saves you 2-7 days of CRM admin + ongoing config work.

#### Khata book (informal accounting)
- **Zoho**: Not a feature. You'd build a custom Khata workaround in Zoho Books or as a custom CRM module.
- **RealEstateFlow**: Native Khata book module. Tracks settlements + payments + auto-links to deals.
- **Verdict**: Mumbai brokers can't ignore Khata; this is a categorical difference.

#### WhatsApp / Telegram integration
- **Zoho**: WhatsApp Business API integration via Zoho IM (extra cost; needs WhatsApp BSP onboarding which can take weeks). Telegram via custom integration only.
- **RealEstateFlow**: Native WhatsApp + Telegram interface. AI Employee replies on these channels. Same WhatsApp number reused.
- **Verdict**: For Mumbai brokers (80%+ workflow on WhatsApp), this is the deciding factor.

#### AI Employee
- **Zoho**: Zia AI for sales scoring + email writing. Not a conversational employee on WhatsApp.
- **RealEstateFlow**: AI Employee qualifies leads, schedules site visits, follows up buyers, updates Khata — all on WhatsApp/Telegram. Optional ₹7,999/mo fully-managed add-on.
- **Verdict**: Categorically different products in this dimension.

#### Pricing
- **Zoho**: ₹800-2,400/user/mo per plan tier (Standard / Professional / Enterprise / Ultimate). Annual contracts get discount; monthly more expensive.
- **RealEstateFlow**: ₹999/mo (1 user), ₹1,999/mo (3 users), ₹500 per extra seat. AI Employee ₹7,999/mo. No tier-locking — features included.
- **Verdict**: For a 3-broker Mumbai agency, RealEstateFlow is 30-60% cheaper at parity for broker workflows.

#### Setup + onboarding
- **Zoho**: 2-7 days of configuration; learning curve days-weeks; Zoho admin certifications exist for a reason.
- **RealEstateFlow**: <30 min self-serve; founder-personal call optional.
- **Verdict**: Time-to-value is a categorical difference.

#### India + DPDP fit
- **Zoho**: Indian company; broadly compliant; data centres in India.
- **RealEstateFlow**: Indian company; AWS ap-south-1; DPDP-first design from Day 1.
- **Verdict**: Both adequate; both Indian.
