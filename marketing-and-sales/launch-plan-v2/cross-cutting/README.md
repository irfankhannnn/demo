# Cross-cutting References

6 reference docs used across all phases. Read these before starting Block 0; revisit weekly during execution.

## Files

| File | Purpose |
|---|---|
| `pre-execution-checklist.md` | Tick before T-21 starts (legal, infra, vendors, founder bandwidth) |
| `vendor-urls.md` | Every vendor signup URL, dashboard URL, cost, used-by task file |
| `skill-command-sheet.md` | Every Claude/Cascade skill mapped to input + output |
| `existing-asset-reuse-map.md` | Reuse / rewrite / retire decisions for all M1-existing assets |
| `asset-production-calendar.md` | When each asset gets produced + by whom |
| `risks-mitigations.md` | P0-P3 risks + mitigations + escalation routing |

## How AI agent should consume this folder

When unsure about:
- Which vendor / signup URL → `vendor-urls.md`
- Which skill to use → `skill-command-sheet.md`
- Whether to reuse vs rewrite an existing asset → `existing-asset-reuse-map.md`
- When to schedule producing an asset → `asset-production-calendar.md`
- What could go wrong + the mitigation → `risks-mitigations.md`
- Whether the launch is ready to start → `pre-execution-checklist.md`

These are append-only logs (decisions + risks + asset moves). Update as launch executes.
