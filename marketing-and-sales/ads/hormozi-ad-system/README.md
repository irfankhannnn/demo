# Hormozi Ad System — RealEstateFlow

## Overview
This folder implements the **Alex Hormozi 50 Hooks × 3-5 Meats × 1-3 CTAs** ad creation system, adapted for **RealEstateFlow OS** targeting Indian real estate agency owners and agents.

## The Math
| Component | Count | Result |
|-----------|-------|--------|
| Hooks | 50 | 50 angles |
| Meats | 4 | × 4 |
| CTAs | 3 | × 3 |
| **Total Ads** | **600** | **per batch** |

## Files in This Folder
| File | Purpose |
|------|---------|
| `hormozi-50-hooks.md` | 50 hooks across 5 sources |
| `hormozi-meats.md` | 4-5 ad body formats with scripts |
| `hormozi-ctas.md` | 3 CTA frameworks with copy |
| `hormozi-ad-matrix.md` | Combination matrix + priority tiers |
| `weekly-filming-guide.md` | How to film 150-750 ads in one session |

## Usage Workflow
1. Read `hormozi-50-hooks.md` — pick 10 hooks to test first
2. Read `hormozi-meats.md` — pick 2 meat formats (demo + testimonial)
3. Read `hormozi-ctas.md` — use CTA 1 and CTA 2
4. Shoot all hooks in ONE filming session (2 hours)
5. Shoot all meats in ONE filming session (3 hours)
6. Shoot all CTAs in ONE session (30 min)
7. Edit in Premiere/CapCut — combine Hook + Meat + CTA
8. Result: 10 × 2 × 2 = 40 ads from first batch

## Levels of Awareness (Spread Your Hooks)
- **Unaware:** "I didn't know I had a lead problem"
- **Problem Aware:** "I know I'm losing leads, don't know fix"
- **Solution Aware:** "I know CRM exists, not convinced"
- **Product Aware:** "I know RealEstateFlow, not bought yet"
- **Most Aware:** "Ready to buy, need final push"
