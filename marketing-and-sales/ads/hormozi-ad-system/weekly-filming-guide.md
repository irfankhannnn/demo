# Weekly Filming Guide — Hormozi Ad System

> **Goal:** Shoot 150-750 ads worth of footage in ONE production day.
> **Equipment:** Smartphone (iPhone 13+ or Pixel 7+) + ring light + lapel mic.

---

## FILMING SESSION SCHEDULE

### Session 1 (9:00 AM – 11:00 AM): ALL 50 HOOKS
**How to film hooks:**
- Each hook: Read card, look at camera, deliver in 3-5 seconds
- Film 3 takes of each hook (pick best in edit)
- Move FAST — 50 hooks × 3 takes = 150 clips in ~90 minutes
- Don't overthink — raw, authentic works better than perfect

**Energy levels:**
- Start with energy (hooks 1-15)
- Take 5-min break after 25 hooks
- Finish strong (hooks 26-50)

**For Hinglish hooks:**
- Film English version first
- Film Hinglish version second
- Both go to different ad sets for testing

---

### Session 2 (11:30 AM – 2:30 PM): ALL MEATS

**Meat 1 — Demonstration (Screen Recording) — 45 min**
- Record CRM dashboard walkthrough (full 45s version)
- Record shortened 15s version

**Meat 2 — Testimonial — 60 min**

**Meat 5 — Faceless (Screen Recording) — 30 min**

## EDITING WORKFLOW

### Software Options
- **Free:** CapCut (mobile + desktop), DaVinci Resolve
- **Paid:** Adobe Premiere Pro, Final Cut Pro
- **AI-Assisted:** Opus Clip (auto-cuts long video into short ads)

### Editing Template (for each ad)
```
[Hook] → [Meat] → [CTA]
0:00-0:03 → 0:03-0:45 → 0:45-1:00
```

### Batch Editing Process
1. Create sequence: Hook clip → Meat clip → CTA clip
2. Add captions: Auto-generate, clean up, style with brand font (Inter Bold)
3. Add music: Artlist/Epidemic Sound — keep at 15% volume
4. Add text overlays: Key stats, brand name, pricing (where required)
5. Export: MP4, H.264, 1080×1920 (Reels), 1080×1080 (Feed), 1920×1080 (YouTube)
6. Name file: `[Hook#]_[Meat#]_[CTA#]_[Platform]_[Date].mp4`

### File Naming Convention
- `H04_M3_C3_META_20260301.mp4` = Hook 4 + Meat 3 + CTA 3 + Meta platform
- `H41_M5_C2_REELS_20260301.mp4` = Hook 41 + Meat 5 + CTA 2 + Reels
