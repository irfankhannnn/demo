**Report Date:** February 2026

## Executive Summary

Cloudberry CRM is a full-stack real estate CRM platform designed for India & Dubai markets. For the Mumbai launch, we're targeting **RERA-registered brokerages and boutique agencies** with a focus on teams managing 1-50 properties.

**Market Opportunity:**
- TAM: 50,000+ RERA-registered brokers/agencies in Mumbai
- SAM: 8,000-12,000 brokerages with 2+ agents (scalable operations)
- SOM (3yr): 2,000-3,000 qualified leads converted to paying customers

## Part 1: Product Feature Analysis & Positioning

### A. Core Product Features

**1. Lead & Deal Management**
- LeadList, LeadDetails, B2BLeadsList
- Enquiry tracking (EnquiryList)

**3. Property & Project Management**
- Property database (residential, commercial, rental)

**4. AI-Powered Calling Suite** ⭐ (KEY DIFFERENTIATOR)

- Knowledge base management

- Real-time call insights
- Multi-language voice support (Hindi, English, regional)

**5. Sales Intelligence & Analytics**
- Business analytics dashboard
- Deal pipeline tracking
- Agent performance metrics
- Calendar & meeting coordination
- Hierarchy management (team structures)

**6. Multi-Platform Access**
- Web (React + TypeScript)
- Mobile (iOS & Android via Capacitor)
- Desktop-grade features on mobile

## Part 5: Lead Scoring Model for Mumbai Launch

### Lead Score Formula

```
Lead Score (0-100) =
  Firmographic Fit (40%) +
  Behavioral Signals (30%) +
  Timing & Readiness (30%)
```

### Scoring Breakdown

#### A. Firmographic Fit (0-40 points)

| Factor | Score | Criteria |
|--------|-------|----------|
| **Company Size** | 10 pts | 2-50 agents (optimal: 5-15) |
| | 7 pts | 50-100 agents |
| | 4 pts | 1 agent or 100+ agents |
| **Revenue Segment** | 10 pts | ₹50L - ₹5Cr annually (sweet spot) |
| | 6 pts | ₹5-10Cr or ₹20-50L |
| | 2 pts | <₹20L or >₹10Cr |
| **Location Tier** | 10 pts | South Mumbai, Central Mumbai, Navi Mumbai |
| | 6 pts | Western Suburbs, Eastern Suburbs, Thane |
| | 2 pts | Outer suburbs (Lower propensity) |
| **Specialization** | 5 pts | Residential sales (core focus) |
| | 3 pts | Mixed (residential + rental) |
| | 1 pt | Commercial-only, niche |
| **Tech Maturity** | 5 pts | Using cloud tools (Sheets, Zoho, Notion) |
| | 2 pts | Manual spreadsheets + WhatsApp |
| | 0 pts | Completely paper-based |

**Scoring Result:** 40 = Grade A (Hot) | 28-39 = Grade B (Warm) | 15-27 = Grade C (Cool) | <15 = Grade D (Cold)

#### B. Behavioral Signals (0-30 points)

| Behavior | Points |
|----------|--------|
| Visited website/landing page | +5 |
| Downloaded competitor comparison guide | +5 |
| Attended webinar on "Lead Management" | +5 |
| Opened 3+ emails from our campaign | +5 |
| Clicked CTA ("Get Demo") | +10 |
| Posted on LinkedIn about CRM/sales tools | +5 |
| Connected with competitor agent on LinkedIn (churn signal) | +5 |
| Searched "CRM for real estate" in past 30 days | +5 |
| Recently hired new agent (scale signal) | +10 |

#### C. Timing & Readiness (0-30 points)

| Timing Signal | Points |
|---|---|
| Budget cycle aligned (Jan, Apr, Jul, Oct in India) | +10 |
| Recent lead leakage complaint (social listening) | +8 |
| Recent agent joined firm (onboarding need) | +7 |
| Attended real estate conference/meetup | +5 |
| Annual planning season (Dec-Jan) | +5 |
| Competitive threat (similar firm upgraded) | +10 |
| Founder/partner actively recruiting (growth mode) | +8 |
