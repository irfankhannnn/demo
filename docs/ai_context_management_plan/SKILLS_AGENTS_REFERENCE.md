## 🔄 DETAILED INTER-AGENT DEPENDENCIES

### 1. BUILDER TEAM DEPENDENCIES
```
architect
├─ Creates module specs → shared with entire team
├─ Uses: codebase-analysis
└─ Triggers: sentry (security audit), pr-commander (design review)

sentry
├─ Reviews: architect's code designs
├─ Outputs: Security checklist → pr-commander must verify
└─ Uses: security-audit, codebase-analysis

pr-commander
├─ Reviews: Outputs from architect, sentry
├─ Requires: Code quality + security clearance from sentry
└─ Uses: pr-review, codebase-analysis
```

### 2. STRATEGIST TEAM DEPENDENCIES
```
deep-researcher
├─ Conducts ICP analysis → feeds trend-hunter & oracle
├─ Outputs: Firmographic data, personas
└─ Uses: icp-research, customer-research

trend-hunter
├─ Consumes: ICP from deep-researcher
├─ Analyzes: Competitor signals, market trends
└─ Uses: trend-analysis, competitor-profiling

oracle
├─ Consumes: Data from deep-researcher + trend-hunter
├─ Predicts: Feature prioritization, market opportunities
└─ Uses: market-prediction, analytics-tracking
```

### 3. CONTENT FACTORY DEPENDENCIES
```
brand-strategist (LEAD)
├─ Defines: Brand tone, Hinglish style, positioning
├─ Creates: Brand kit → fed to ALL content creators
├─ Uses: brand-strategy, positioning
└─ Feeds → nano-designer, motion-engineer, ugc-planner, seo-content-writer, landing-page-builder

nano-designer
├─ Consumes: Brand kit from brand-strategist
├─ Creates: Ad banners, social graphics
├─ Uses: image, nano-banana-pro, ad-creative
└─ Feeds → media-buyer (for ad campaigns)

motion-engineer
├─ Consumes: Brand kit + creative direction from brand-strategist
├─ Creates: Videos, demos, explainers
├─ Uses: video, prompt-generator, higgsfield
└─ Feeds → media-buyer (for video ads)

ugc-planner
├─ Consumes: Brand kit + product positioning from brand-strategist
├─ Creates: UGC scripts, influencer briefs
├─ Uses: ugc-scripts, ad-creative, marketing-psychology
└─ Feeds → media-buyer (for UGC campaigns)

orator
├─ Consumes: Scripts from motion-engineer + ugc-planner
├─ Creates: Voiceovers, subtitles
├─ Uses: voiceover-gen
└─ Feeds → motion-engineer (for video finalization)

landing-page-builder
├─ Consumes: Brand kit + copy from brand-strategist
├─ Creates: Landing pages with CRO
├─ Uses: landing-page, form-cro, page-cro, copywriting
└─ Feeds → media-buyer (as campaign landing pages)

seo-content-writer
├─ Consumes: Brand positioning from brand-strategist
├─ Creates: Blog articles, SEO content
├─ Uses: seo-blog, seo-audit, ai-seo, programmatic-seo
└─ Feeds → All teams (content library)
```

### 4. SCALERS TEAM DEPENDENCIES
```
lead-scraper (FIRST)
├─ Enriches: Raw leads with Apollo/Clay logic
├─ Uses: lead-enrichment, serpapi-scraping
└─ Outputs → ab-optimizer, sdr, nurture-bot, pipeline-manager

ab-optimizer
├─ Consumes: Creative from nano-designer + motion-engineer + ugc-planner
├─ Monitors: ROAS, CPA, winner campaigns
├─ Uses: ab-testing, ab-test-setup, analytics-tracking
└─ Feeds → media-buyer (scale winners, pause losers)

media-buyer
├─ Consumes: 
│   ├─ Creatives from nano-designer
│   ├─ Videos from motion-engineer
│   ├─ Scripts from ugc-planner
│   ├─ Landing pages from landing-page-builder
│   └─ Winners from ab-optimizer
├─ Creates: Meta/Facebook campaigns
├─ Uses: paid-ads, launch-strategy, co-marketing
└─ Feeds → ab-optimizer (for monitoring)
```

### 5. CONVERTERS TEAM DEPENDENCIES
```
sdr (OUTBOUND)
├─ Consumes: 
│   ├─ Lead list from lead-scraper
│   ├─ Personas from deep-researcher
│   ├─ Messaging from brand-strategist
├─ Creates: Personalized outbound campaigns
├─ Uses: cold-email, outbound-outreach, whatsapp-outreach, sales-enablement

nurture-bot (FOLLOW-UP)

├─ Uses: lead-nurture, email-sequence, marketing-psychology

### 6. OPERATIONS DEPENDENCIES
```
pipeline-manager
├─ Consumes:
│   ├─ Enriched leads from lead-scraper

## 🎯 TYPICAL WORKFLOW: 3,000 Lead Campaign (RealtyFlow)

```
1️⃣ STRATEGY PHASE (Strategists)
   deep-researcher → ICP Analysis (Indian real estate agents)
   trend-hunter → Market signals, competitor pricing
   oracle → Feature prioritization, messaging angles
   ↓
   Outputs: Target persona, messaging pillars, positioning

2️⃣ BRAND & CONTENT PHASE (Content Factory)
   brand-strategist → Brand manifesto, Hinglish tone guide
   ├─ nano-designer → Hero banners, social ads
   ├─ motion-engineer → Demo video
   ├─ ugc-planner → UGC scripts
   ├─ orator → Voiceover for video
   ├─ landing-page-builder → Lead capture page
   └─ seo-content-writer → Blog content
   ↓
   Outputs: Complete creative suite (images, video, copy, landing page)

3️⃣ LEAD GENERATION PHASE (Scalers)
   lead-scraper → Scrape + enrich 3,000 leads from Google Maps
   media-buyer → Launch Facebook/Instagram campaigns
   ├─ Uses: Banners from nano-designer
   ├─ Uses: Video from motion-engineer
   ├─ Uses: Scripts from ugc-planner
   └─ Uses: Landing page from landing-page-builder
   ↓
   Outputs: 3,000 leads captured

4️⃣ TESTING PHASE (Scalers)
   ab-optimizer → Monitor ROAS, CPA, creative winners
   ↓
   Outputs: Winning creative + audience combo

5️⃣ OUTREACH PHASE (Converters)
   sdr → Send personalized email/WhatsApp/LinkedIn
   nurture-bot → Automate follow-ups, handle objections
   ↓
   Outputs: Qualified pipeline

6️⃣ TRACKING PHASE (Operations)
   pipeline-manager → Track pipeline, daily summaries
   ↓
   Outputs: Performance dashboard, ROI report
```

## 📞 WHO CALLS WHOM (Call Chain for Common Tasks)

### Task: "Launch a new ad campaign"
```
User
  ├─ Calls: orchestrator OR media-buyer directly
  │   ├─ Needs from: nano-designer (creative)
  │   ├─ Needs from: landing-page-builder (LP)
  │   ├─ Needs from: lead-scraper (audience)
  │   └─ Monitors with: ab-optimizer
```

### Task: "Create a product launch campaign"
```
User
  ├─ Calls: orchestrator
  │   ├─ Orchestrator calls: brand-strategist
  │   │   ├─ brand-strategist calls: deep-researcher (audience insights)
  │   │   ├─ brand-strategist calls: trend-hunter (competitive analysis)
  │   │   └─ Outputs: Brand messaging → feeds all content creators
  │   │
  │   ├─ Orchestrator calls: nano-designer (uses brand-strategyist output)
  │   ├─ Orchestrator calls: motion-engineer (uses brand output)
  │   ├─ Orchestrator calls: ugc-planner (uses brand output)
  │   ├─ Orchestrator calls: landing-page-builder (uses brand output)
  │   │
  │   ├─ Orchestrator calls: media-buyer (uses all creative outputs)
  │   ├─ Orchestrator calls: lead-scraper (enriches audience)
  │   └─ Orchestrator calls: ab-optimizer (monitors performance)
```

### Task: "Generate leads and qualify them"
```
User
  ├─ Calls: orchestrator
  │   ├─ Orchestrator calls: lead-scraper (scrape + enrich)
  │   ├─ Orchestrator calls: sdr (send outbound)
  │   ├─ Orchestrator calls: nurture-bot (follow-up)
  │   ├─ Orchestrator calls: pipeline-manager (track results)
  │   └─ Orchestrator calls: ab-optimizer (optimize messaging)
```

### Task: "Create a landing page"
```
User
  ├─ Calls: landing-page-builder directly OR orchestrator
  │   ├─ Needs: Brand kit from brand-strategist
  │   ├─ Optimizes with: form-cro, page-cro skills
  │   ├─ Uses copy from: brand-strategist or seo-content-writer
  │   └─ Feeds output to: media-buyer (for campaigns)
```
