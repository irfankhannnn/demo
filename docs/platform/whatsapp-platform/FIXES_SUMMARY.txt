FIX #1: CRITICAL BUG — Backend networkError Field Not Integrated
────────────────────────────────────────────────────────────────

PROBLEM:
  Backend's getConnectionStatus() detected network errors and returned 
  networkError: true, but frontend's fetchConnectionStatus() didn't check 
  this field. Network errors were classified as 'unknown' instead of 'network'.

IMPACT:
  Users saw generic "unknown error" instead of helpful "network error" message.

SOLUTION:
  1. Frontend: Check err.networkError flag in fetchConnectionStatus()
  2. Backend: Pass networkError flag in auth route error response

FIX #2: MINOR BUG — formatWhatsAppPhone Fallback Inconsistency
──────────────────────────────────────────────────────────────

PROBLEM:
  Function returned original input in fallback case, which could contain 
  spaces/dashes. International numbers returned with original formatting.

IMPACT:
  Inconsistent phone display in UI (some formatted, some not).

SOLUTION:
  Return normalized digits in fallback instead of original input.
