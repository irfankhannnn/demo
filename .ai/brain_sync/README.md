# Brain Sync

This directory stores cross-session summaries and state snapshots.

Files here are generated after significant milestones to help future sessions pick up context quickly without re-analyzing the entire codebase.

## Naming Convention
- `YYYY-MM-DD-session-summary.md` — Per-session progress and decisions
- `milestone-*.md` — Major feature or refactor completion notes

## How to Use
When starting a new session, read the most recent summary here after loading .ai/PROJECT_CONTEXT.md and .ai/context.md.
