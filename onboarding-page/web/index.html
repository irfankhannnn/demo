Tenant Onboarding
Creates tenant credentials in DynamoDB AgencyConfig table for CRM login.
POST /api/onboard
TenantId format: <agency-slug>-<randomhash>
Example: happy-properties-1a2b3c4d5e
How CRM will login
Send header x-tenant-id with the generated tenantId, then call /api/auth/login with username/password.
DynamoDB write
Writes item with PK TenantId into table in AGENCY_CONFIG_DYNAMODB_TABLE_NAME.
Tips
Use AWS profile locally (recommended). Configure it in onboarding-page/.env.
See README.md for setup.
