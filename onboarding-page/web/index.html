Tenant Onboarding
Provisions a new agency tenant. Admin can then login via Google or Phone OTP.
POST /api/onboard
At least one of Email or Phone is required. Both can be provided.
TenantId format: <agency-slug>-<randomhash>
Example: happy-properties-1a2b3c4d5e
How Admin will login
Admin goes to CRM login page and uses Google OAuth (if email provided) or Phone OTP (if phone provided).
DynamoDB write
Writes to auth agency table (dev-reality-flow-auth-agency-config) with TenantId, adminEmail, adminPhone.
Tips
Use AWS profile locally (recommended). Configure it in onboarding-page/.env.
See README.md for setup.
