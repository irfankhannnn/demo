## Writing Rules for SEO + Hinglish

### Keyword Placement Strategy
```
1. H1 Title: Include primary keyword naturally
   ✅ "How to Close 25% More Real Estate Deals"
   ❌ "Real Estate Deals Closing Keyword Optimization"

2. Meta Description: Include keyword + benefit (155 chars max)
   ✅ "Learn how to close more real estate deals faster. Strategies from 500+ Indian agents. Start free."
   ❌ "This is an article about real estate deals"

3. First 100 words: Use keyword in first paragraph
   ✅ "Closing real estate deals faster is every agent's dream..."
   ❌ Start with generic intro, keyword later

4. H2 headings: 2-3 should include related keywords naturally
   ✅ "H2: How to Follow Up on Real Estate Leads Faster"
   ✅ "H2: Build Your Real Estate Sales Strategy Around Automation"

5. Body copy: Keyword density 1-2% (naturally)
   ✅ Mix keyword with synonyms: "deals", "sales", "transactions", "closures"
   ❌ Keyword stuffing: "real estate deals, real estate deals, real estate deals..."
```

### Hinglish Writing for SEO

```
Grammar Mix (70/30 Rule):
✅ "Real estate agents karate hain daily 50+ WhatsApp messages."
✅ "Close more deals by automation. Focus on relationship building."
✅ "Apne team ko manage karte time leads fail nahi hona chahiye."

Avoid:
❌ Pure Hindi: "Real estate agents har din 50+ WhatsApp messages prante hain."
❌ Indianized English: "Agents are daily catching WhatsApp messages very much."
❌ Hindi + English separated: "Real estate agents [HINDI SENTENCE] regularly."

Emotional Hooks (Use Hindi):
- "Aapka sapna" (your dream)
- "Shakti de" (empower)
- "Safalta" (success)
- "Apna" (own)
- "Samajhna" (understand)
- "Badlav" (change)

Technical Terms (Use English):
- "Automate"
- "Analytics"
- "Integration"
- "Platform"
- "Workflow"
- "Dashboard"
- "Follow-up"
```

## On-Page SEO Checklist

- [ ] **H1 Tag:** Exactly one, includes primary keyword, 50-60 chars
- [ ] **Meta Title:** Keyword at start, benefit statement, 50-60 chars
- [ ] **Meta Description:** Compelling, includes keyword, 150-160 chars
- [ ] **URL Slug:** Keyword-based, hyphens, lowercase (e.g., `/close-more-deals-real-estate`)
- [ ] **First Paragraph:** Contains keyword naturally, <100 words
- [ ] **H2 Headings:** 3-5 headings, 1-2 contain related keywords
- [ ] **Body Length:** 800-1,200 words minimum
- [ ] **Images:** At least 2, with alt text containing keyword
- [ ] **Internal Links:** 3-5 links to other RealtyFlow blog posts
- [ ] **External Links:** 1-2 authoritative sources (Indian real estate associations, etc.)
- [ ] **Keyword Density:** 1-2% (keyword appears 8-15 times naturally)
- [ ] **Readability:** Flesch-Kincaid Grade 8 (simple language)
- [ ] **Bullet Points:** 3-5 key takeaways at end
- [ ] **CTA:** Clear call-to-action in conclusion
- [ ] **Mobile Rendering:** Test on phone (easy to read)
