# UGC Scripts Skill

Write authentic, high-converting UGC scripts targeting Indian real estate agents. Includes proven copywriting frameworks, hook libraries, and video compositing commands.

## Script Frameworks

### Framework 1: PAS (Problem-Agitate-Solution)

**Best for:** Lead gen, pain point ads, feature-focused content

```markdown
# UGC Script: "Leads Manager Pain" (PAS)

**Duration:** 30 seconds | **Voice:** Casual, energetic | **Tone:** Relatable frustration → relief

---

## PROBLEM (0-8s)
**Visuals:** Agent scrolling through multiple apps, stressed expression, chaos on screen
**Voiceover:** "Ek WhatsApp group mein buyers, dusre mein sellers, tisre mein miscellaneous leads...
aur phone calls har time ringing?"

**Hinglish Ratio:** 80% English, 20% Hindi
**Camera:** Wide shot of desktop, then close-up of frustrated face
**Music:** Minor key, tense (80 BPM)
**On-Screen Text:** "The Daily Chaos"

---

## AGITATE (8-18s)
**Visuals:** Speed-montage of switching apps, missing notifications, losing deals
**Voiceover:** "Ek lead bhool jao, aur deal gone. Spreadsheet outdated? Lead lost.
Tab sochna padta hai... kitna time barbaad hua?"

**Hinglish Ratio:** 70% English, 30% Hindi
**Camera:** Rapid cuts, zooms on missed notifications
**Music:** Tempo increases, violin screech SFX
**On-Screen Text:** "Missed leads = Missed income"

---

## SOLUTION (18-30s)
**Visuals:** Smooth transition to clean RealtyFlow dashboard, features sliding in
**Voiceover:** "Ab RealtyFlow mein sab kuch ek jagah. Buyers, sellers, owners, leads—
all tracked, all AI-powered, zero subscription. Download karo. Ab aur zyada tension nahi."

**Hinglish Ratio:** 60% English, 40% Hindi
**Camera:** Smooth pans across dashboard, zooms on features
**Music:** Resolves to upbeat, positive (120 BPM)
**On-Screen Text:** "All leads, one app" → "Download RealtyFlow"
**CTA:** "Download Now" (blinking)

---

## Audio Mix
- **Voiceover:** 1.0 volume (primary)
- **Music:** 0.4 volume (background)
- **SFX:** Notification dings (0.6 volume) on missed calls
```

## Camera Direction Templates

### Interview (Talking Head)

```markdown
**Setup:**
- Camera at eye level (phone on stand, or tripod)
- Natural lighting (window light or softbox)
- Casual setting (office, coffee shop, home—authentic)
- White or muted background (no distractions)

**Directions:**
- Speak naturally, as if talking to a friend
- Maintain eye contact with camera
- Use hand gestures (authentic, not robotic)
- No teleprompter—conversational flow
- 1-2 takes, keep it real

**Audio:**
- Lapel mic or phone microphone (clean, no background noise)
- Record in quiet space
- Consider adding subtle background music in post
```

### B-Roll (Supporting Footage)

```markdown
**Dashboard/App Usage:**
- Screen recording at 4K resolution
- Slow pans across features (not too fast)
- Zoom on key metrics (deals closed, lead count)
- Cursor clicks visible for clarity
- 5-10 second clips per scene

**Office/Workspace:**
- Wide establishing shot of workspace
- Close-ups of phone/laptop with app
- Agent using app in real workflow
- Authentic moments (no staged poses)
- Overhead shots of notes, leads, deal pipeline

**Location Shots:**
- Real estate property walkthroughs
- Agent meeting with clients
- Hustle/work montage (closing calls, signing docs)
- Fast cuts (2-3 seconds per clip)
```

### Transitions

```markdown
**Smooth Cuts:**
- Cut on action (agent taps screen → dashboard appears)
- Fade to black between major scenes (1-2 seconds)
- Wipe transitions (left-to-right, for modern feel)

**Text Overlays:**
- Emerge from bottom (100ms slide-up)
- Hold for 2-3 seconds minimum
- Fade out smoothly (200ms)
- Font: Bold, readable (Montserrat or Poppins)

**Audio Transitions:**
- Music crossfade (500ms overlap)
- SFX on key moments (notification ding, success chime)
```

## Hinglish Script Writing Guidelines

### Grammar Rules

1. **Sentence Structure:** English base + Hindi inflection
   - ✓ "Ek app mein sabhi leads" (not "Sabhi leads ek app mein")
   - ✓ "Zero subscription, lifetime free" (punchy, English order)

2. **Verbs:** Use English verbs, Hindi tense indicators
   - ✓ "Download karo" (English verb + Hindi imperative)
   - ✓ "Deal close ho gaya" (English noun + Hindi past tense)
   - ✗ "Karo download" (too forced Hindi)

3. **Numbers & Metrics:** Always in English
   - ✓ "3000+ agents, 12 deals/month"
   - ✗ "Teen hazar agents, barah deal"

4. **Exclamations:** Mixed, energetic
   - "Haan! Exactly!"
   - "Bilkul sach!"
   - "Aur haan, absolutely free!"

### Vocabulary Examples

| English | Hinglish | Context |
|---------|----------|---------|
| frustrated | frustrated / stressed | "Mujhe frustrated feel ho raha tha" |
| scattered | scattered | "Leads scattered across 5 apps" |
| organize | organize karo | "Organize karo sabhi leads ek jagah" |
| transform | transform ho gaya | "Business completely transform ho gaya" |
| download | download karo | "Download karo ab" |
| subscribe | subscribe karna | "Kisi aur app ko subscribe karna padta tha" |

### Tone Examples

**Casual & Friendly:**
- "Sach kahu to..." (Honestly, if you ask me...)
- "Ek minute..." (Hold on a sec...)
- "Samajh gaye na?" (You get what I mean?)

**Energetic & Excited:**
- "Bilkul amazing!"
- "Zero subscription? Haan!"
- "First month mein hi 5 deals!"

**Confident & Assured:**
- "Ab paisa double karunga."
- "RealtyFlow ke saath, guaranteed."
- "3000+ agents ne already trust kiya."

### Common Mistakes to Avoid

| ✗ Wrong | ✓ Correct | Reason |
|--------|-----------|--------|
| "Leads manage karnega" | "Leads manage karo" | Use imperative for action |
| "Main download karta hoon" | "Download karo" | Too formal, kill energy |
| "Bahut expensive tha" | "Bilkul expensive tha" | Stronger emphasis |
| "Mujhe pasand aa gaya" | "Mujhe bilkul pasand aa gaya" | Add intensity particle |

## FFmpeg Compositing Commands

### Picture-in-Picture (Agent + Dashboard)

```bash
# Main: Agent interview (left 60%), B-roll: Dashboard (right 40%)
ffmpeg -i agent-interview.mp4 -i dashboard-broll.mp4 \
  -filter_complex "[0]scale=1296:1080[left];[1]scale=624:1080[right];[left][right]hstack" \
  -c:v libx264 -c:a aac output-pip.mp4
```

### Side-by-Side Comparison (Before/After)

```bash
# Before (left) vs After (right) for BEFORE-AFTER framework
ffmpeg -i before.mp4 -i after.mp4 \
  -filter_complex "[0]scale=960:1080[before];[1]scale=960:1080[after];[before][after]hstack=inputs=2" \
  -c:v libx264 -c:a aac output-comparison.mp4
```

### Green Screen Removal (Chroma Key)

```bash
# Remove green background, replace with blurred app screen
ffmpeg -i agent-green.mp4 -i app-background.mp4 \
  -filter_complex "[0]chromakey=0x00ff00:0.1[agent];[1][agent]overlay" \
  -c:v libx264 -c:a aac output-greenscreen.mp4
```

### Slideshow (Multiple Testimonial Photos)

```bash
# Create slideshow from 5 images (2s each)
ffmpeg -framerate 1/2 -i "testimonial-%d.jpg" \
  -c:v libx264 -vf "scale=1080:1920,fps=30" \
  -c:a aac output-slideshow.mp4
```

### Watermark + Text Overlay (Both)

```bash
# Add watermark (logo) + text overlay (caption)
ffmpeg -i video.mp4 -i logo.png \
  -vf "overlay=W-w-10:H-h-10,drawtext=textfile='caption.txt':x=50:y=100:fontsize=28:fontcolor=white" \
  -c:v libx264 -c:a aac output-branded.mp4
```

### Multi-Angle Cut (3 angles in grid)

```bash
# 3 camera angles in 3x1 grid
ffmpeg -i angle1.mp4 -i angle2.mp4 -i angle3.mp4 \
  -filter_complex "[0]scale=360:1080[a1];[1]scale=360:1080[a2];[2]scale=360:1080[a3];[a1][a2][a3]hstack=inputs=3" \
  -c:v libx264 -c:a aac output-triple-angle.mp4
```

### Caption/Subtitle Compositing

```bash
# Burn subtitles + title card
cat > captions.srt << 'EOF'
1
00:00:00,000 --> 00:00:05,000
Itne saare apps use kar rahe ho?

2
00:00:05,000 --> 00:00:12,000
RealtyFlow ek app mein sab kuch
EOF

ffmpeg -i video.mp4 -vf "subtitles=captions.srt:force_style='FontSize=32,PrimaryColour=&HFFFFFF&'" \
  -c:v libx264 -c:a aac output-captions.mp4
```
