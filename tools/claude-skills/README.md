## Environment Variables Needed

Get these API keys and set them in Claude Cowork:

```bash

ELEVENLABS_API_KEY=sk_...                # Voiceovers
SERPAPI_API_KEY=...                      # Lead scraping
META_ADS_ACCESS_TOKEN=EAA...             # Facebook/Instagram ads
```
