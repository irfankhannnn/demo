# Brand Strategy — RealtyFlow (Hinglish)

Create brand positioning assets for RealtyFlow. Focus: $ARGUMENTS

## Brand Positioning

```
Target: Indian real estate agents/agencies (Mumbai, Pune, Delhi, Bangalore)
Problem: Lead chaos, manual follow-ups, no tech control
Solution: CRM built specifically for real estate workflows
Differentiator: Built by real estate people, Hinglish-native, simple
```

## Hinglish Writing Rules
1. Natural code-switching (70% English, 30% Hindi romanized)
2. Emotion in Hindi ("tension mat lo"), technical in English ("CRM", "pipeline")
3. Conversational fillers: "yaar", "bhai", "dekho", "suno"
4. Currency: ₹, crore, lakh — never million/billion
5. Must sound spoken, not written

## Deliverables

### 1. Brand Manifesto
Structure: Problem → Realization → Solution → Promise → Invitation
- 200-300 words, Hinglish, emotional + practical
- Address: WhatsApp chaos, Excel nightmares, missed follow-ups

### 2. Taglines (5 options)
Categories: Control | Ease | Growth | Problem | Aspirational
- Max 8 words each, at least one Hindi word, benefit-first

### 3. Tone-of-Voice Guide
- Personality: Casual + Expert + Supportive
- Do's: street-smart confidence, practical advice, relatable frustration
- Don'ts: corporate jargon, formal English, condescending tone

### 4. Brand Keywords (Hinglish vocabulary)
20+ words/phrases with usage examples: "aasaan", "kaam chalu", "ek click mein"

### 5. Messaging Matrix
Map 6+ pain points → Hinglish message → channel → audience segment
