## Creator Notes

### Tone & Feel
- [ ] Authentic, NOT polished
- [ ] Conversational, like talking to a friend
- [ ] Genuine enthusiasm, NOT overhyped
- [ ] Professional but relatable

### Do's
- [ ] Use natural lighting (window light preferred)
- [ ] Show real reactions to the product
- [ ] Include specific numbers or results
- [ ] Memorize key points (don't read script word-for-word)
- [ ] Film in landscape + vertical (both versions)

### Don'ts
- [ ] No studio lighting (too polished)
- [ ] No teleprompter (too stiff)
- [ ] No corporate jargon
- [ ] No rushing the hook (let it breathe)
- [ ] No fake enthusiasm
